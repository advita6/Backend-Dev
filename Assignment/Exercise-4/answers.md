# Database Selection

## 1. Online Banking System

**Type:** SQL
**Reason:** Requires strong consistency, transactions (ACID), and data integrity for financial operations.

## 2. Social Media Platform

**Type:** NoSQL
**Reason:** Handles large-scale unstructured data, high scalability, and flexible schema for posts, likes, etc.

## 3. Real-time Chat Application

**Type:** NoSQL
**Reason:** Needs fast read/write operations and horizontal scaling for real-time messaging.

## 4. Hospital Patient Records

**Type:** SQL
**Reason:** Requires strict consistency, structured data, and secure transactions.

## 5. IoT Sensor Data Collection

**Type:** NoSQL
**Reason:** Handles massive streaming data, high write throughput, and flexible schema.
